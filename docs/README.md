## Context boundary

This documentation is intentionally suitable for a public repository. Private Kois strategy, relationship details, legal working notes, private asset permissions, and long-term brand or portfolio implications belong in the private [`kois-context`](https://github.com/kois-studio/kois-context) repository and should be referenced rather than copied here.
