# Kois Gallery landing

The public marketing and documentation site for Kois Gallery. It is a static Astro site deployed independently from the self-hosted Angular/NestJS product.

The page content intentionally reflects the current first-beta product boundary. Keep future capabilities clearly marked until they are implemented and verified in the root product.

## Commands

Run these commands from `landing/`:

```sh
npm install
npm run dev
npm run build
npm run preview
```

The canonical production URL is `https://gallery.kois.app`.
